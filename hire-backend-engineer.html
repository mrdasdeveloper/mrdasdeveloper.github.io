Frequently Asked Questions

Questions I get from engineering managers and CTOs

What's your usual backend stack?
FastAPI or Node/Express for APIs, PostgreSQL for relational data, Redis for cache and queues, Docker to ship. I also know Django well and can work in whatever stack your team already runs.
Can you own schema design and the API layer?
Yes. Schema, API, auth, Redis caching, and Docker/CI deploy — I take that whole path when you need one backend owner instead of three separate handoffs.
How do you approach performance work?
Profile first, then fix what hurts: slow queries and indexes, Redis for hot reads, async where the main thread would block, Celery for heavy jobs, connection pools. On past systems that often meant about 25–35% better response times.
Have you built microservices and distributed backends?
Yes — greenfield services and splits from a monolith. Docker, gateway patterns, service-to-service calls, event messaging, and independent deploys are normal parts of that work.
Where are you based, and can you work remote?
Kathmandu, Nepal (UTC+5:45). I work remote with US, EU, Middle East, and Asia teams. Full-time or long contracts both work. WhatsApp +977-9700864900 is the fastest start.
